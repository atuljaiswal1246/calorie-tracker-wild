1. `git bundle create ~/.calmatters-git-backup/pre-purge-2026-09-27.bundle --all`
   — 115 MB, `git bundle verify` → **"The bundle records a complete history"**.
2. `git filter-repo --path tmp_images --invert-paths --force`
   (installed for this: `git-filter-repo` was **not** present; BFG not present.
   A stale `.git/filter-repo` state dir from an earlier `--version` probe was

   had been half-filtered.)
3. `git push --force origin 'refs/heads/*:refs/heads/*'` and the same for tags.
   Branches `main`, `wip-mascot-all-work`; tags `v0.9.6`, `mascot-work-head`.

**All commit hashes changed** (`352a650 → b83f1a8` on main). Anyone with another
clone must re-clone or `git fetch && git reset --hard origin/main`. That is the
known cost of the purge, accepted by the owner.

## The lesson that outlasts this

**A single passing run is not evidence.** Earlier the same session reported a
prompt fix as "proven" from one run per prompt; repeated runs showed the two
prompts were indistinguishable. The same rule now applies to *this* purge: one
`git log` would have looked convincing, which is why the proof is a fresh clone
and a byte-level hash of every blob — not a grep for a filename.
